# Release Notes v0.1.0

## Summary

Initial public release of the `product-userguide-docx` skill.

## Included Capabilities

- Generate Chinese product user guides in `.docx` format from live websites
- Support both PC menu-based systems and mobile H5 products
- Capture screenshots for pages, popups, and workflow downstream pages
- Place screenshots under the matching operation steps
- Normalize route-style page names into Chinese product terminology
- Refine existing manuals against a reference `.docx`

## Included References

- workflow rules
- platform mode rules
- screenshot rules
- document template
- page naming rules
- review checklist

## Notes

- This release focuses on reusable skill instructions and helper references.
- It does not include real business screenshots, credentials, or customer documents.
